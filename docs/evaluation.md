# 评测说明与结果

[返回首页](../README.md) · [使用指南](getting_started.md)

## 评测内容

在 LIBERO 仿真环境中，让机器人根据语言指令完成操作任务。对同一模型，分别评测原始精度与 RTN 四位量化，比较任务表现及资源占用。

| 任务集合 | 主要能力 |
| :--- | :--- |
| 空间关系 | 理解物体的位置与相对关系 |
| 目标物体 | 识别并操作指定物体 |
| 任务目标 | 理解指令并完成指定目标 |
| 长时程操作 | 连续完成多步操作 |

每个集合包含 10 项任务，每项重复 50 回合。同一轮比较使用相同的任务、初始状态和随机种子。三模型、两种方法、四个集合共 24 个组合、12,000 回合。

## 指标怎么看

| 指标 | 含义 | 阅读方式 |
| :--- | :--- | :--- |
| 任务成功率 | 成功完成操作的回合占比 | 越高越好 |
| 平均成功率 | 所选任务集合成功率的平均值 | 完成全部四个集合后显示四集合平均 |
| 查询耗时 | 模型收到一次请求到输出动作的耗时 | 同一模型内越短越好 |
| 运行峰值显存 | 推理期间进程占用的显存峰值 | 越低越节省显存 |
| 加载峰值显存 | 模型加载期间框架分配显存的峰值 | 与运行峰值分开读取 |

不同模型一次预测的动作数量不同，查询耗时不宜直接跨模型比较，也不等于机器人完成整个动作的时间。显存单位为 GiB。

## 展示结果

以下为交互演示所用的已完成评测结果。原始精度采用 BF16；RTN 使用 4 位权重、每组 128 个权重。FastWAM 使用首帧模式。

| 模型 | 方法 | 四集合平均成功率 | 平均查询耗时（毫秒） | 运行峰值显存（GiB） |
| :--- | :--- | ---: | ---: | ---: |
| OpenVLA | 原始精度 | 76.95% | 207.3 | 15.01 |
| OpenVLA | RTN | 73.95% | 318.8 | 6.70 |
| VLA-Adapter | 原始精度 | 97.55% | 64.9 | 4.47 |
| VLA-Adapter | RTN | 93.75% | 86.2 | 3.49 |
| FastWAM | 原始精度 | 96.80% | 311.8 | 24.02 |
| FastWAM | RTN | 96.85% | 370.3 | 16.74 |

在这组结果中，RTN 降低了显存占用，但查询耗时增加。OpenVLA、VLA-Adapter 的成功率有所下降；FastWAM 的成功率接近原始精度，0.05 个百分点的差异不足以认定性能提升。

<details>
<summary>数据口径</summary>

- 成功率来自 12,000 个正式任务回合；耗时与显存来自单独的固定输入测量。
- 表中查询耗时为四个集合平均查询耗时的均值；运行峰值显存取四个集合中的最大值。
- 本组显存数据的实际采样间隔为 100 毫秒，可能遗漏短时峰值；不应据此推断显卡容量的精确下限。
- 本组资源记录保留了权重路径与量化配置，但未保存完整权重文件指纹；数值用于呈现这组实验条件下的结果。
- AWQ、HSA 不包含在本组结果中。演示数据不是新一轮实时评测。
